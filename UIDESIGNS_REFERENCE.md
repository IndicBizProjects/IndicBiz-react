| Goal | Go-To Repo |
|---|---|

| Cursor effects & interactive animations | **react-bits** → `Animations/` |
| Text effects & rolling headlines | **react-bits** → `TextAnimations/` |
| Smooth Framer Motion components | **motion-primitives** → `components/core/` |

| SaaS landing page sections | **shadcn-dashboard-landing-template** → `src/components/` |
| Data charts & analytics | **tremor** → `src/components/` |
| Quick semantic Tailwind UI | **daisyui** (class-based) |
| Enterprise-level form components | **flowbite-react** |
| Input/form variations (copy-paste) | **originui** → `components/` |
